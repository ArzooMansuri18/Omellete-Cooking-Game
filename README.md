<h1>🍳 Omelette Cooking Game</h1>

<p>A fun, interactive web-based game where players can master the art of making the perfect omelette! Built with a clean UI and smooth animations.</p>

<h2>🚀 Features</h2>
<ul>
<li>Interactive Cooking: Click through the steps to crack eggs, whisk, and fry.</li>
<li>Dynamic Visuals: Real-time CSS animations for a satisfying kitchen experience.</li>
<li>Responsive Design: Fully playable on both desktop and mobile browsers.</li>
</ul>

<h2>🛠️ Built With</h2>
<ul>
<li>HTML5: Semantic structure for the kitchen environment.</li>
<li>CSS3: Custom styling, layouts, and cooking animations.</li>
<li>JavaScript (ES6+): Game logic, state management, and event handling.</li>
</ul>

<h2>🎮 How to Play</h2>
<ul>
<li>Open index.html in any modern web browser.</li>
<li>Follow the prompts to prepare your ingredients.</li>
<li>Complete the steps before the timer runs out (or simply enjoy the process!).</li>
</ul>
